# Glyph Click

Photo → thermal print on a Cashino CSN-A1 (58 mm, 384 dots).

| Folder | Version | Status |
|---|---|---|
| [`glyph_cam_direct/`](glyph_cam_direct/) | **Laptop only**: the laptop processes the photo and prints over the printer's USB | ready |
| `with_s3/` | ESP32-S3: on-device processing, WiFi printing, camera later | coming next |

Photos to print go in `images/`. This folder is not tracked in git.
